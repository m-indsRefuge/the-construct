# The Construct

A tiny autonomous computational world inspired by:

- Alan Turing — explicit computation from simple rules
- John von Neumann — constructors, self-description, and self-modifying machinery
- Stephen Wolfram — complex behavior emerging from simple computational systems

The Construct contains a sandboxed micro-world populated by purely computational
inhabitants whose symbolic Wolfram programs can execute, mutate, compose, construct,
and eventually rewrite their own machinery.

A later phase will introduce an autonomous LLM Steward with constrained influence
over the environment.

## Current milestone

World Zero:

- Micro-OS / World Core
- symbolic inhabitants
- mutable Wolfram programs
- computational contracts
- resource system
- live Textual observatory
